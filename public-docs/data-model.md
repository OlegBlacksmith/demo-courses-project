# Модель данных

База — PostgreSQL с расширением pgvector, доступ через Prisma 7. Схема разбита на файлы
в `apps/web/prisma/`: `catalog.prisma` (каталог) и `users.prisma` (пользователи и доступ).

## Каталог
Курс состоит из модулей, модуль из уроков, урок из компонентов.

- Статусы курса: DRAFT, PUBLISHED, HIDDEN, ARCHIVED.
- Статусы модуля и урока: DRAFT, PUBLISHED. Неопубликованный модуль скрывает свои уроки.
- HIDDEN и ARCHIVED убирают курс с витрины, но купившие сохраняют доступ.

## Переводы
Оригинал на русском хранится в основной таблице, остальные языки — в таблицах `…Translation`
со своим статусом. На витрине показывается только опубликованный перевод, иначе оригинал.

## Роли и доступ
- Роль пользователя задаёт права на платформе: USER, INSTRUCTOR, CURATOR, ADMIN.
- Ученик — это не роль, а наличие записи на курс (`Enrollment`).

## Прогресс
На пользователя и урок хранится одна запись; урок пройден, если заполнен `completedAt`.
Процент не хранится, а считается по опубликованным урокам опубликованных модулей.

## Слой данных
Запросы к базе находятся в `apps/web/src/data/` и выполняются только на сервере.
Наружу отдаются DTO с минимальным набором полей.

## Тестовые данные
Сид (`apps/web/prisma/seed.ts`) сначала **удаляет все данные** в базе, поэтому запускайте его
только локально. Тексты уроков в нём пока заглушки.

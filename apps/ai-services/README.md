# ai-services

Python-сервис с ИИ-инструментами для витрины курсов. Сейчас тут каркас:
FastAPI, проверка здоровья и заготовка переводчика на фейковом LLM-клиенте.

## Запуск

```
uv sync                  # создать .venv и поставить зависимости по uv.lock
uv run ai-services       # запустить сервер на http://127.0.0.1:8000
```

Документация API открывается сама: http://127.0.0.1:8000/docs

## Проверки

```
uv run pytest            # тесты
uv run ruff check .      # линтер
uv run ruff format .     # форматирование
```

## Что где лежит

```
pyproject.toml           зависимости и настройки инструментов
uv.lock                  точные версии всех зависимостей
.python-version          версия Python для проекта
.env.example             пример настроек; копируется в .env
src/ai_services/
  __init__.py            точка входа `uv run ai-services`
  config.py              настройки из переменных окружения и .env
  app.py                 сборка FastAPI-приложения
  api/                   эндпоинты и их зависимости
  llm/                   интерфейс LLM-клиента и фейковая реализация
tests/                   тесты
```
